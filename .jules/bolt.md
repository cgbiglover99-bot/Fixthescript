## 2024-10-17 - Compose Performance: Isolate TextField State and Use mutableStateListOf
**Learning:** In the Jetpack Compose setup of the Vesper app, tying the high-frequency state update of a `TextField` (i.e., `inputText`) directly within the main `VesperUI` composable causes the entire screen (including the `LazyColumn` for chat history) to recompose on every keystroke. Furthermore, using `var chatHistory by remember { mutableStateOf(listOf<String>()) }` forces the creation of a new list and triggers a recomposition on every addition.
**Action:** Isolate high-frequency state updates like `TextField` into their own separate composables to avoid full-screen recompositions. Additionally, use `mutableStateListOf` instead of `mutableStateOf(listOf())` for O(1) list appends and to allow Compose to optimize list rendering without recreating the entire list object.
