## 2024-05-18 - Jetpack Compose Performance: State Management
**Learning:** For Jetpack Compose performance in this codebase, always isolate high-frequency state updates (like text inputs) into separate composables to avoid full-screen recompositions, and use `mutableStateListOf` instead of `mutableStateOf(listOf())` for O(1) list appends. Also, remember that when passing a `mutableStateListOf` to an async function, we need to pass a snapshot using `.toList()` to avoid `ConcurrentModificationExceptions`.
**Action:** Replace `var chatHistory by remember { mutableStateOf(listOf<String>()) }` with `val chatHistory = remember { mutableStateListOf<String>() }` in `MainActivity.kt`, and extract the `TextField` into a separate composable to prevent the whole screen from recomposing on every keystroke.
