## 2025-01-20 - Jetpack Compose Performance: State Isolation and List Appends
**Learning:** In a highly interactive Jetpack Compose UI (like a real-time chat with speech-to-text), keeping high-frequency state updates (e.g., text inputs) in the main screen's root composable triggers costly full-screen recompositions. Additionally, using `mutableStateOf(listOf())` for a growing chat history creates unnecessary object copies on every list append, which can become a bottleneck as history grows.
**Action:** Always isolate high-frequency state updates (like text inputs) into their own child composables (e.g., extracting `ChatInputArea`) to contain recomposition scope. For dynamically growing lists, strictly use `mutableStateListOf` instead of `mutableStateOf(listOf())` to achieve O(1) appends without creating new list copies.
