## 2024-05-15 - Isolate high-frequency Compose state and optimize List append
**Learning:** In Jetpack Compose, modifying a state variable like `inputText` in a large UI component causes the entire component to recompose. For the chat UI in this codebase, extracting the `TextField` into its own `VesperInputArea` composable isolates the `inputText` state, preventing full-screen recompositions of `VesperUI` on every keystroke. Additionally, appending to a `mutableStateOf(listOf())` is O(N) since it copies the list. Using `mutableStateListOf()` reduces this to O(1).
**Action:** Always isolate high-frequency state updates (like text inputs) into separate composables to avoid full-screen recompositions, and use `mutableStateListOf` instead of `mutableStateOf(listOf())` for O(1) list appends in chat interfaces.
