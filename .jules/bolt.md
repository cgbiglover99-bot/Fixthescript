## 2026-10-30 - [Optimize Jetpack Compose State and Recomposition]
**Learning:** In Jetpack Compose, passing a mutable list to a composable or holding a list with `mutableStateOf` causes a full recomposition when the list changes (O(N) copy). Also, reading `mutableStateListOf` from an asynchronous callback without a snapshot leads to `ConcurrentModificationException`. Placing high-frequency state updates like `TextField` inside the main UI composable causes full-screen recompositions on every keystroke.
**Action:** Use `mutableStateListOf` for lists to allow O(1) appends. Always pass `list.toList()` (a snapshot) to asynchronous callbacks to prevent CME. Extract high-frequency state update components (like text inputs) into separate composables to isolate recomposition scopes.
